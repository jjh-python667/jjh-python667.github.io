资讯台 Newsdesk

STAY CURIOUS. / A personal intelligence desk

在信息的噪声中，找到值得读的信号。把国内外 AI、科技与商业资讯汇集到自己的阅读台。

查看源码 ↗下载源码返回作品
FIND THE SIGNAL.

为什么做

希望把分散在国内外不同网站的 AI、科技与商业资讯集中起来，按自己的阅读节奏筛选、收藏和继续阅读，同时保留原文出处。

A PERSONAL READING ROOM.

当前实现

  • Cloudflare Workers 提供界面、API 和每 30 分钟运行的采集任务，D1 保存新闻与阅读状态。
  • 内置 25 个 RSS / Atom 来源，支持分类、地区、关键词和未读 / 收藏筛选。
  • 真实原文链接、异步已读保存、有限重试、单源错误隔离和采集诊断。
  • 原生动画实现标题遮罩开场、模块标题进场、卡片 stagger 与插画轻微视差，适配减少动态效果。
TESTED WITH CONTEXT.

验证与当前状态

2026-11-09 的个人部署回报为 25 个来源中 24 个成功。36氪会向 Workers 返回人机验证页面，已有文章保留，之后的轮次继续尝试。来源可用性会随对方站点变化。

新版前端完成 24 项本地回归与自动无障碍检查，另有来源页导航定向检查。测试使用本地模拟接口，覆盖搜索竞争、收藏、已读、分页、来源管理、原文导航、错误反馈和减少动态效果；不等于真实云端 Access、D1 或手机网络已经完成发布后验收。

页面 HTML 离线 gzip 约 14KB，没有额外加载外部动画库、字体、视频或 WebGL。开场结束后释放动画，插画离屏后移除滚动监听。项目在 AI 编程助手辅助下开发和验证。

TRY IT ON YOUR DESK.

自己运行

下载源码后，在 Node.js 20 或更新版本中运行 npm run preview，即可打开仅使用固定演示数据的本地界面，无需安装生产依赖。部署真实采集需要自己的 Cloudflare Worker、D1 和 Access 配置。

作者的私人实例入口 ↗ 需要本人登录，没有向访客开放的阅读账户。公开作品页和源码不会索取你的 Cloudflare 凭据。

THE HONEST LIMITS.

能力边界

新闻源可能限流、超时或拦截云端请求。翻译标题和中文摘要目前仅预留字段，尚未接入模型；这是单人资讯工具，不提供多用户账户隔离。真实设备滚动帧率与线上冷网络仍需按发布版本验收。
