FIND THE OPPORTUNITY.

为什么做

免费额度、学生资源和数字服务优惠常常分散在不同页面。我希望把公开来源中的信息集中起来，先用中文读懂大意，再回到原文核对参与条件。

它是公开信息的整理工具。来源没写的金额、地区、期限或资格，继续显示「待核实」。

LESS NOISE. MORE CONTEXT.

新版实现了什么

  • Cloudflare Workers 与 D1 承载采集和存储，支持 RSS、Atom 与官方页面来源。
  • 按全部、今日、来源标值、即将截止、归档及收藏切换视图；分类、优惠类型和关键词可以组合筛选。
  • 同一记录只渲染一张卡片，每页 12 条；收藏保存在当前浏览器，筛选与页码可以随 URL 恢复。
  • 当前 28 条记录补齐中文标题、摘要和内容简介；原文与中文可切换，常见条件、时长及标值也有中文显示。
  • 适配手机、平板和桌面，补齐无结果恢复、键盘操作、禁用存储降级与减少动态效果。
READ IT. THEN VERIFY IT.

中文内容从哪里来

当前条目的中文整理随源码提供，按来源、英文标题和摘要精确匹配。原文发生变化时会停用旧整理，避免套用过期内容；已保存的后台机器译文优先保留，并单独标注。

新采集的内容不保证立刻有译文，仍可能先显示原文。后台自动翻译代码与独立定时任务已有，但尚未在这次更新中上线、实测。语言切换本身不会调用真实模型。

VERIFIED LOCALLY.

验证与当前状态

本机 44 项测试、类型检查和 24 项浏览器交互验收通过，覆盖三页中文内容、原文切换、收藏、筛选、分页与异常状态。320、360、390、768、1024、1440 像素宽度均检查了页面溢出和主要控件。

Worker dry-run 构建通过。GitHub 中提供 Windows / Ubuntu 的自动检查；这些结果不等于线上 D1、真实模型、冷网络或完整采集流程已经完成发布后验收。

前端没有视频、WebGL、外部字体或额外动效库；复用日期格式器、去除重复卡片，并尊重系统减少动态效果设置。项目由 AI 编程助手辅助开发、整理中文和验证。
